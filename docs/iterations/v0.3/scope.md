# v0.3 Scope: Favorites and User Playlists

v0.3 delivers persistent track favorites and flat, user-owned playlists with
stable ordering. It excludes history, recommendations, M3U, cloud sync,
accounts, online playlists, queue editing, and Android.

Favorites and playlists are durable media-library relations. Playback state
continues to belong exclusively to PlaybackRuntime.
